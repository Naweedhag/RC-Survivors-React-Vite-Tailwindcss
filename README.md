🧟 Resident Evil News Hub 

✨ Features

- 4 News Categories - Games, Updates, Movies & Series, and Lore & Secrets
- Product Catalog - 15+ official Resident Evil products with real images
- Category Filtering - Browse news by category
- Responsive Design - Fully responsive with Tailwind CSS
- Modern UI - Beautiful gradients, hover effects, and smooth animations
- React Router - Seamless navigation between pages

🛠️ Tech Stack

- React 18 - UI Library
- Vite** - Build Tool
- Tailwind CSS - Styling
- React Router DOM v6 - Routing
- React Icons - Icon library (Font Awesome & Game Icons)
